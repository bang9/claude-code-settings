# Step 3 — Read the target

Load the target into context before judging it.

- Read the target `SKILL.md` in full.
- Read every file it routes to — whatever the directory or file names. A skill may use
  `references/`, `scripts/`, `steps/`, or any other layout, so follow the actual links, not
  fixed names. Read prose and instruction files as-is; for a script/executable, inspect
  purpose, invocation, and syntax, and skip implementation detail unless it carries agent
  instructions.

Continue to step 4 once you have read everything the skill routes to.
